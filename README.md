# LocalChat

一个 Windows 本地收件箱，用聊天的方式给自己保存文字、截图和文件。

**无需账号，不上传聊天数据。** 使用 C#、WPF 和 SQLite 构建，采用 [MIT 许可证](LICENSE)。

## 功能

- **随手记录**：文字、多附件消息、文件拖放、截图和文件粘贴。
- **本地附件**：发送时复制原件，源文件移动或删除后仍能访问；原文件不压缩、不转码。
- **查看与保存**：图片缩略图和原图预览；视频及其他文件通过系统关联程序打开。支持保存、另存为和文件定位。
- **查找记录**：文字、文件名、日期和类型组合查询，支持中文子串搜索、历史消息定位及分页。
- **简洁交互**：右键气泡操作、窄窗口布局、可拖动调整高度的输入框。
- **可配置**：数据目录、导出目录、发送快捷键和下次启动的默认窗口尺寸。

## 开始使用

如仓库已提供 Release，可下载 Windows x64 发布包，解压后运行 `LocalChat.exe`。自包含发布版不需要另装 .NET 运行时；源码开发需要 **Windows 和 .NET 10 SDK**。

| 操作 | 方式 |
| --- | --- |
| 默认发送 / 换行 | `Enter` / `Shift+Enter` |
| 另一种发送方式 | 设置中关闭 Enter 发送，改用 `Ctrl+Enter` 发送、`Enter` 换行 |
| 粘贴 | `Ctrl+V`，支持文字、截图、复制的文件 |
| 设置 / 搜索 / 添加文件 | 输入框左下角的齿轮、放大镜、文件夹图标 |
| 复制、编辑、删除 | 右键消息气泡；纯文件消息仅显示删除 |
| 调节输入框高度 | 拖动输入框上沿短横线 |
| 退出设置 | 右上角“×”或 `Esc`，不保存修改 |

普通消息删除直接执行，不再二次确认。使用“打开”会打开内部附件原件；需要编辑且保留原件时，先“另存为”。

## 数据存储

| 内容 | 默认位置 |
| --- | --- |
| 配置 | `%LOCALAPPDATA%\LocalChat\settings.json` |
| 数据库及附件 | `%LOCALAPPDATA%\LocalChat\Data` |
| 导出文件 | `%USERPROFILE%\Downloads\LocalChat` |

```text
Data/
├── localchat.db             # 消息、附件属性及关联关系
├── attachments/YYYY/MM/     # 唯一 ID 命名的原件，按 UTC 导入年月归档
└── cache/                   # 可重建的图片缩略图
```

“保存”和“另存为”都导出副本，不移动内部原件。数据目录迁移要求目标为空，成功后保留旧目录；迁移失败不会切换配置，但可能留下部分副本。请勿手工移动内部附件。

### 卸载

设置底部的“卸载 LocalChat（包含记录）”经单独确认后，退出应用并清理当前程序、数据库、内部附件、缓存和配置。**导出文件和开发源码保留**。清理范围包含当前、默认及已登记的历史数据目录，不扫描全盘删除其他程序副本或旧版未登记目录。详见[存储与卸载说明](docs/ARCHITECTURE.md)。

## 开发与构建

在仓库根目录执行：

```powershell
.\build.ps1                  # 编译解决方案
.\build.ps1 -Test            # 编译并运行集成测试
.\build.ps1 -Test -Publish   # 测试并发布自包含 win-x64 程序
```

发布输出为 `dist/LocalChat/`。也可以直接运行源码：

```powershell
dotnet run --project src/LocalChat
```

正常构建不需要 Python；只有重新生成图标时需要 Python 和 Pillow。

## 当前边界

- 本地数据尚未加密；未实现应用锁、备份恢复、云同步或自动更新。
- 搜索文字和文件名，不索引 PDF/Word 正文，不提供 OCR。
- 图片预览取决于系统解码器；视频使用系统播放器，无内嵌播放或转码。
- 崩溃可能遗留导入临时文件或无引用附件，暂不自动清理未知文件。
- 卸载依赖系统 PowerShell；受策略或文件占用影响时会报告失败，不自动调整安全策略。
