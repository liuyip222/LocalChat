# 架构与数据

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `App.xaml` / `.cs` | 共享样式、单实例和应用启动 |
| `MainWindow.xaml` / `.cs` | 聊天 UI、搜索、消息操作、异步预览和操作互斥 |
| `ChatStore.cs` | SQLite 表、参数化查询、附件导入、导出和迁移 |
| `Models.cs` | 消息、附件、设置和搜索参数 |
| `SettingsWindow.cs` | 设置输入、验证、即时快捷键提示和取消操作 |
| `WindowAppearance.cs` | Windows 11 原生标题栏配色，不支持时保留系统外观 |
| `Uninstaller.cs` | 卸载文件清单及应用退出后的清理助手 |

当前采用简单的视图事件与独立存储服务，没有额外引入 Web 服务、依赖注入容器或大型 UI 框架。

## 存储模型

- `messages`：文字、UTC 创建时间、编辑时间。
- `attachments`：唯一 ID、相对路径、大小、类型和 SHA-256。
- `message_attachments`：消息与附件关联、原始文件名、顺序。

附件原件存文件系统，不存入数据库 BLOB。当前不做内容去重：相同文件可多次发送，各自拥有原件。SHA-256 在导入时计算，不等同于已实现自动完整性修复。

## 导入、导出与查询

1. 流式复制到 `.importing` 文件，并计算哈希。
2. 刷盘后改为正式文件名，数据库事务写入消息和附件关联。
3. 成功后清空输入；正常异常路径清理本次文件，保留未发送内容。

数据库和文件系统之间不是同一个原子事务，进程崩溃仍可能遗留无引用文件。缩略图是可重建缓存。

消息采用 ID 游标分页，每页 `ChatStore.PageSize` 条。搜索使用参数化中文子串查询，不依赖分词；时间区间转换成 UTC，结束日按次日零点排除。UI 以本地时间显示。

导出默认避让重名，不删除内部原件；另存为经系统覆盖确认后，以旁路临时文件替换目标。迁移复制整个数据目录、切换配置，保留原目录，不自动删除旧数据。

## 卸载边界

卸载先生成具体文件清单，拒绝链接/重定向路径，等待主进程退出后逐文件清理；目录仅在空时移除。不会自动降低 PowerShell 执行策略，也不对整个用户目录执行递归删除。

包含：当前程序 EXE/PDB、当前/默认/登记历史目录中的数据库、内部附件、图片缓存、临时截图、标准单文件运行缓存和配置。保留：导出副本、不匹配内部命名的其他文件、开发源码、独立复制的其他版本及未登记的历史迁移副本。

测试通过可注入的配置和临时根目录构造清单，避免扫描真实用户位置。测试不启动卸载助手。
