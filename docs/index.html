聊天记录在哪里？

默认在 %LOCALAPPDATA%\LocalChat\Data。其中 localchat.db 保存消息和附件索引，attachments 保存原文件，cache 保存缩略图。可在设置中更换数据目录。

备份时先关闭应用，再复制整个数据目录，不要只复制数据库。

本地保存，是不是就等于加密？

不是。LocalChat 无需账号，不上传聊天数据，但目前没有数据库加密或应用锁。同一台电脑上的其他有权限的程序或用户仍可能访问这些文件。

本页是公开的工具介绍页，不会连接应用，也不会读取本地聊天记录。

为什么安装包比想象中大？

自包含发布版将 .NET 与 WPF 运行环境一并打包，换来解压即用、无需另装运行时。体积主要来自运行环境，不是聊天记录；具体大小以发布附件为准。

支持哪些系统和功能？

目前面向 Windows x64，使用 C#、WPF 和 SQLite 构建。不提供网页版聊天、云同步、OCR、翻译或自动更新。图片预览依赖系统解码器，其他格式可交给系统关联程序打开。

如何反馈问题或参与开发？

在 GitHub Issues 描述复现步骤和系统版本；提交截图或日志前请移除私人信息。开发说明见 贡献指南。
