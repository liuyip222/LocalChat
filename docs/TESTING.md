# 测试说明

## 自动化

```powershell
.\build.ps1 -Test
```

`tests/LocalChat.Tests` 使用独立临时目录，执行后仅清理自身测试目录。覆盖：

- 旧配置默认值和窗口尺寸序列化；输入区启动最小高度、重启重置及紧凑外边距/拖动条布局。
- 文字与附件持久化，删除源文件后访问原件。
- 中文/文件名/类型/时间查询、重名导出和游标分页。
- 消息编辑、删除、导入失败回滚与迁移约束。
- 相对路径边界、卸载清单隔离及无关文件保留。
- 截图反向拖动、桌面边界、移动/缩放约束、150% DPI 像素换算及精确尺寸舍入、隐藏窗口选项序列化。
- STA 合成图片渲染：方框/圆框、箭头、中文文字、字号和颜色/粗细、马赛克平均块及图层顺序、裁剪尺寸、源图不变、撤销/重做历史。
- 紧凑工具栏：九个图标顺序、参数默认收起、工具专属参数、六色选择、填充/线框切换、字体/马赛克三档大小、切回选区模式以及两行控件渲染尺寸。
- 合成剪贴板 PNG 流/字节数组与 Bitmap 解码、文字格式回退；气泡文本选择、紧凑尺寸、共享右键菜单与输入区粘贴命令绑定（不改动系统剪贴板）。
- 图片复制数据的原图尺寸、像素与透明度、PNG/Bitmap 格式、源文件释放与缺失处理；图片下方复制按钮及非图片附件隐藏（不改动系统剪贴板）。
- 聊天像素滚动与虚拟化配置；单格/高精度滚轮步长、连续滚动、反向响应、积压限制和边界；真实离屏 WPF 列表的混合高矮气泡与图片、滚轮中间帧、最终位置、文本内滚轮及跳转/鼠标操作取消动画。

卸载测试只生成清单，不执行助手、不删除真实应用或记录。所有断言通过时输出 `SUCCESS`；实际断言数量以运行输出为准。

## 手工回归

选区界面可使用合成图片单独验收（不会读取真实桌面或修改剪贴板）：

```powershell
dotnet run --project tests/LocalChat.Tests -- --screenshot-ui
```

确认后输出到被 Git 忽略的 `artifacts/screenshot-ui-result.png`。此测试入口刻意显示任务栏图标以便 UI 自动化定位，实际截图浮层不显示任务栏图标。

在独立 Windows 测试账户或一次性测试安装中验证：

1. 单行/长文本、换行、多附件、剪贴板图片和拖放。
2. 图片预览、未知格式文件卡片、外部播放器、保存与另存为。
3. 日期/类型/关键词搜索、历史定位、加载更早记录和搜索关闭。
4. 窄窗口、滚动条、任务栏图标、输入框高度调节和右键菜单。
5. 设置保存/取消、即时快捷键提示及重启后的默认窗口大小。
6. 目录迁移后的内容与重启验证；无权限/磁盘写入失败场景。
7. 在可丢弃数据和程序副本上验证卸载确认、退出后清理及失败提示，确认导出和无关文件保留。
8. 截图/隐藏窗口截图、取消后窗口恢复、剪贴板粘贴、截图加入待发送列表；多显示器、负坐标及不同系统缩放。确认不把遮罩、选择框、工具栏一起截入。
9. 截图选区后逐一绘制方框、正圆、箭头、多行文字和马赛克；展开/收起参数栏、小中大、实心填充、六色、撤销重做、再次点击当前工具恢复选区调整、确认合并输出。
10. 拖选气泡内部分文字后 Ctrl+C 与右键“复制”；未选中时右键复制整条消息。检查长文本换行及消息不可直接改写。
11. 使用 Win+Shift+S 截图后回到输入框 Ctrl+V，确认加入待发送图片；同时验证普通文字、替换选中文字、文件粘贴与发送后的图片内容。
12. 点击图片下方“复制图片”，在画图、Word 或其他聊天程序粘贴；检查原图尺寸、透明背景以及退出 LocalChat 后仍能粘贴。验证 JPEG 图片、缺失/损坏原件及剪贴板暂时被占用的提示。
13. 在聊天文字、图片和空白处缓慢/快速/反向滚动，确认单格小步长与平滑过渡；测试顶部/底部、拖动滚动条、键盘导航、返回最新、搜索定位和加载更早消息。输入框滚轮保持独立；不同 DPI 和高精度滚轮的实际手感需人工验收。

## 环境限制

遇到 `0x800711C7` 时，可能是 Windows 应用程序控制策略阻止开发程序集。交由设备管理员按现有签名/开发程序流程处理，不要把“编译成功”当作“运行测试通过”。项目不自动修改系统安全策略。

GitHub Actions 将在 Windows runner 中编译、运行断言并生成构建产物；工作流存在不代表已在远端执行通过。UI 和真实卸载不属于该自动化覆盖范围。
