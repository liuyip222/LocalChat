# 测试说明

## 自动化

```powershell
.\build.ps1 -Test
```

`tests/LocalChat.Tests` 使用独立临时目录，执行后仅清理自身测试目录。覆盖：

- 旧配置默认值和窗口尺寸序列化。
- 文字与附件持久化，删除源文件后访问原件。
- 中文/文件名/类型/时间查询、重名导出和游标分页。
- 消息编辑、删除、导入失败回滚与迁移约束。
- 相对路径边界、卸载清单隔离及无关文件保留。

卸载测试只生成清单，不执行助手、不删除真实应用或记录。所有断言通过时输出 `SUCCESS`；实际断言数量以运行输出为准。

## 手工回归

在独立 Windows 测试账户或一次性测试安装中验证：

1. 单行/长文本、换行、多附件、剪贴板图片和拖放。
2. 图片预览、未知格式文件卡片、外部播放器、保存与另存为。
3. 日期/类型/关键词搜索、历史定位、加载更早记录和搜索关闭。
4. 窄窗口、滚动条、任务栏图标、输入框高度调节和右键菜单。
5. 设置保存/取消、即时快捷键提示及重启后的默认窗口大小。
6. 目录迁移后的内容与重启验证；无权限/磁盘写入失败场景。
7. 在可丢弃数据和程序副本上验证卸载确认、退出后清理及失败提示，确认导出和无关文件保留。

## 环境限制

遇到 `0x800711C7` 时，可能是 Windows 应用程序控制策略阻止开发程序集。交由设备管理员按现有签名/开发程序流程处理，不要把“编译成功”当作“运行测试通过”。项目不自动修改系统安全策略。

GitHub Actions 将在 Windows runner 中编译、运行断言并生成构建产物；工作流存在不代表已在远端执行通过。UI 和真实卸载不属于该自动化覆盖范围。
